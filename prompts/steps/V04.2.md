# V04.2 — Invariant/Testkit 基础

## Authority
Treat `requirements.docx` / Constitution as non-negotiable P0/P1 law. Follow `AGENTS.md`, `PLANS.md`, `planning/r2_steps.json`, relevant Master/Office specifications, and approved ADRs.

## Gate
- Work package: V04 — 可执行工程门禁与负例验证
- Stage: S1
- Execution mode: `NORMAL`
- Hard dependencies: V04.1

Before implementation, verify the repository status file shows every hard dependency `VERIFIED`. If not, STOP with `BLOCKED_DEPENDENCY`.

## Goal
建立守恒、账本、权限、时间、幂等等测试 harness 和 fixture builders。

## Exit gate
已实现范围有真断言；未实现项明确 NOT_RUN。

## Required workflow
1. Read only the relevant specs/ADRs and inspect current code.
2. Write `docs/exec-plans/V04.2.md` before product code changes.
3. Declare affected authoritative owners, reads/writes/events/commands, DB/RLS/time implications, and legacy impact.
4. Implement only this step. Do not auto-run the next step.
5. Run real unit/integration/invariant/security tests appropriate to this scope. Use `NOT_RUN` honestly.
6. Create `docs/reports/V04.2/IMPLEMENTATION.md` and `TEST_EVIDENCE.json`.
7. Final status must be one of: `IN_PROGRESS`, `IMPLEMENTED_UNVERIFIED`, or `BLOCKED`. Implementation agent may not mark `CHANGES_REQUIRED` or `VERIFIED`.
   - `IMPLEMENTED_UNVERIFIED`: implementation for this step is complete and required local evidence exists, but independent review has not approved it.
   - `IN_PROGRESS`: some work was completed, but the step is not implementation-complete.
   - `BLOCKED`: work cannot safely continue because an external decision, missing prerequisite, environment limitation, or P0/P1 conflict prevents progress.
8. Next action must be independent review, not the next implementation step.

## Universal prohibitions
- No second Source of Truth.
- UI cannot mutate authoritative state.
- No direct macro outcome or hidden buff.
- No production Supabase mutation unless this step explicitly belongs to an approved production release and all gates are satisfied.
- No weakening/skipping P0 tests.
- No silent scope expansion or deletion of original requirements.
