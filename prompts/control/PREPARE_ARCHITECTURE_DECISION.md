# Prepare the minimum architecture decision package

Read `status/decisions.json`, the cited source conflict, affected work packages,
and only the specifications needed for the named ADR. Prepare an ADR using
`templates/ADR.md` with the problem, source evidence, options, proposed choice,
tradeoffs, affected owners, migration or compatibility impact, and required
tests.

Keep the decision `PROPOSED_NOT_APPROVED`. State who must approve and which
steps remain blocked. Do not modify product code, infer approval from silence,
or combine unrelated ADRs merely to unblock implementation.
