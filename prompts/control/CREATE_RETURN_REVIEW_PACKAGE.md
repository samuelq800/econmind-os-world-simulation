# Create a return and review package

For the current step, collect the exact branch and commit, changed-file list,
requirements and ADR references, implementation report, real command results,
test evidence, negative cases, migration and permission effects, legacy impact,
known gaps, and rollback or forward-fix notes. Use the repository templates.

Distinguish `PASS`, `FAIL`, `NOT_RUN`, and `INSUFFICIENT_EVIDENCE`. Do not add
credentials, generated build artifacts, unverified claims, or work from later
steps. End with the requested independent-review action and leave the current
step below `VERIFIED` until the reviewer decides.
