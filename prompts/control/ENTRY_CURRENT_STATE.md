# Inspect the current R2 state

Read `AGENTS.md`, `PLANS.md`, `planning/r2_steps.json`,
`status/progress.json`, and `status/decisions.json`. Inspect Git status, branch,
HEAD, and the latest implementation and independent-review evidence for the
current step.

Report the current step, its exact status, hard dependencies, unresolved ADRs,
evidence gaps, and whether any next step is ready. Do not modify files, approve
decisions, reinterpret `NOT_RUN` as `PASS`, or start implementation. Treat
`requirements.docx` as binding P0/P1 law and report conflicts rather than
choosing a resolution.
