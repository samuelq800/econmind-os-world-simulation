# Season 1 public country read boundary

The interactive country page reads the selected `BALANCED_2026_09_28_V1` country file first. It never derives Office permission from `?role=` or `?country=`; those parameters select only public geography and local planning views. A local decision remains `LOCAL_NOT_EXECUTED`.

An embedding host may set `window.__ECONMIND_WORLD_READ_CONFIG__ = { apiOrigin: 'https://…/' }` before `country-context.js` loads. Do not put a token, service key, World identity or API origin in the URL. The adapter sends a credential-free GET to `/v1/world-data/countries/visual-territory-NN`. A's proposed first contract is `official-country-baseline-v1` with `dataNature: OFFICIAL_SELECTED_SOURCE_DATASET`, package ID, both selection and country-source hashes, `sourcePath: data/countries.json`, country ID, units, `proposalFieldsAreExecuted: false`, `liveWorldState: false`, and the selected source `country` record. It does **not** include scene art, facilities, deposits, opening finance, or a World projection. The adapter verifies the shared country fields against the published static package and continues to render facilities/resources only from that package. Until A's contract passes independent review and is deployed, leave the config unset.

State labels are explicit: `STATIC_BASELINE` (bundled selected data), `API_COUNTRY_VERIFIED` (country source record confirmed by the public API; bundled sites/resources remain separately sourced), `STATIC_DISCONNECTED` (API unavailable/mismatched, bundled data retained), and `MISSING` (no valid selected country data, no substitute numbers). Every result has `runtime: NOT_CONNECTED`. The selected package is source data, not an OpeningSeed commit, live WorldVersion, executed facility, or command receipt. A separate authorized projection adapter can be added only after an authenticated, scope-bound API contract exists; this public adapter must never reinterpret a proposal or URL role as runtime authority.
