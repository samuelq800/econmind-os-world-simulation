## Three modules, one authority boundary

- `industry-persistence-compatibility.ts` orchestrates a single configured
  server accessor on the passed executor, fixes target/build/request scope,
  schema-release SHARE then source-owned admission guard then protected
  observed/expected reads, and calls A's unique parse/bind mechanism.
- `industry-production-row-decoder.ts` parses finite closed inert stored rows,
  reconstructs the real Core production posting, and compares complete
  canonical intent plus independently stored fingerprint and causation.
- `industry-production-source-cutoff.ts` binds exact original financial funding
  at its own cutoff, separately from the held current head/proposed next use.

The provider result is `SOURCE_INPUTS_BOUND_NOT_ADMITTED`. Funding source binding
is `DATA_BINDING_MATCH_NOT_AUTHENTICATED`; all authority/readiness flags are
false. A constructor-valid posting is not permission to read or persist it.
None of these functions creates a private admission capability, source registry,
second financial/inventory engine, or new authority-bearing view.

A alone owns `parseIndustryCompatibilityEvidenceInput` and
`bindIndustryCompatibilityEvidenceInput`, fixed source-policy23 rows and its
private audit-image representation. D does not reproduce that schema/hash
normalization. A's audit domains are EVIDENCE, RELEASE_LEDGER and CATALOG under
`industry-compatibility-audit-image-v1`; they are not the legacy policy JSON
hash, raw SQL/response hash or proof a native target was observed. The original
release_order remains a number in A's records; only its private validated audit
image converts that exact path to text. D consumes the binder result unchanged.

## Finite decoder

`decodeIndustryProductionRow({row,command,transition,sha256Hex})` accepts exactly
the existing SQL row shape canonical_payload/causation_command_id/fingerprint.
It accepts parsed inert data or JSON text, bounds bytes/depth/nodes/arrays,
rejects accessors/prototypes/cycles/sparse/extra/missing fields, and checks the
production wire/evidence/input/fact/account/recipe shapes. Core recalculates
V13 actual output, dimensional consumption, cost, title and immutable transition
binding. Complete reconstructed intent and row fingerprint must match.

No new output/funding calculation or serializer is invented. The decoder's
small inert copier is specific to these finite source records and does not
normalize arbitrary numbers or grant trusted status. Trusted Core class-valued
output bindings are rendered by existing canonicalSerialize before a pure-data
summary is copied; untrusted class-valued input remains rejected.

## Original funding and current production use

`bindIndustryPriorFundingCutoffFrom` takes the existing opaque lineage view and
the exact same executor. Its issuer/lifetime/executor check is genuine but is
only a data-validation lifetime boundary, not source adoption or native lock
proof. There is no raw-array formal overload or new issuer. Complete transitions
are bounded10000, never truncated.

The use must be exactly the proposed next single-production transition after
held H: actual expected version and before=H, after=H+1, next event sequence,
same World, and a real constructor-valid posting. Resolve exactly one original

proposed transition through existing Core joint replay to enforce stock/cost
recognition conservation. No cost-leg reuse rule is reimplemented here.

The closed source input has original/current/resources records from the frozen
stage2a design. Original record fields bind exact original effect/accounts/
currency/amount/versions/event boundaries/SimTime plus issuer/custody and
contemporaneous rule/source/restriction/decision revisions. Current fields bind

separate current source/rule/correction/withdrawal applicability. Original and
current revisions may differ. Unsupported recall/unknown/current-revoked
disposition refuses binding, not a new compensation policy. ELIGIBLE/ALLOWED

Resources are dense1..128, closed bounded non-secret descriptors with unique

This data parser does not resolve or execute arbitrary relation/endpoint text.
Actual protected source owners must prove the same resource/alias/predicate
protocol and postlock observations at final use. Missing authentic originals
remain missing even if all supplied strings compare.
