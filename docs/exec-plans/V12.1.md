## Auditable pool conservation invariant

For one canonical `(world, country, deposit, resource, unit)` identity, let
`G0` be the immutable opening geological endowment and let `U`, `D`, `R`, `V`
and `X` be the exact non-negative quantities in undiscovered, discovered,
recoverable, developed and cumulatively extracted pools. The planned audit
oracle is:

```text
G0 = U + D + R + V + X
remaining underground = G0 - X = U + D + R + V
```

All terms must use the same closed catalog unit; identity or unit mismatch is a
zero-effect rejection. `G0` is opening-bound and never rewritten. A V12.1
exploration/discovery transition of explicit amount `q > 0` has only:

```text
U' = U - q; D' = D + q; R', V', X', G0' = R, V, X, G0
0 < q <= U
```

It therefore preserves the equality and cannot discover more than the hidden
pool. This is an audit requirement, not an authorization to calculate `q`.
The later recoverable/developed/extracted transitions must preserve the same
identity, never skip a documented lifecycle boundary, and must be separately
owned by V12.2 where production inventory posting is introduced.
