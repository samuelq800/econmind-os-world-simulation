## Implementation design

1. Add one independent pure-Core module and barrel export. Reuse the shared
   foundation provenance helpers, exact decimal arithmetic and fixed V22.1
   activity names without editing the V22.1 module.
2. Require every calculation/validation to consume immutable facts bound to one
   source version, predecessor chain, snapshot hash and integer simulation tick.
3. For exact transfer subtypes, reject currency/unit/party mismatch,
   insufficient source balances/capacity, negative values, duplicate parties,
   non-conservation and replay tampering. Return exact transitions; never post.
4. Treaty, sanctions, tender and partnership validators accept only structured
   references. Sanctions reject any intensity field; partnerships reject any
   direct effect/buff field; tender awards cannot exceed requirements or bids.
5. Tests must exercise each of the 23 matrix entries, every dedicated public
   calculator/validator, realistic failure boundaries and replay evidence.
