## Minimal contract

The tool accepts caller-supplied provenance only:

- source ID, availability, SHA-256 digest, locator and explicit time range;
- parameter ID, availability/missing reason, canonical finite decimal value,
  unit, source IDs, transformation ID and formula text;
- economic Event type references affected by the parameter.

An available source without digest/locator/time range, a parameter without a
unit, a non-finite/non-canonical numeric value, unknown/duplicate identities,
or an available parameter without formula/source/Event bindings fails closed.
A declared missing source or parameter produces `UNAVAILABLE` and no inferred
causal-chain row.

For structurally available inputs, output is a deterministic, machine-checkable
`source -> parameter -> economic-event` causal-chain inventory. It preserves
the supplied digest, locator, time range, unit, value, transformation ID and
formula as inert evidence. It does not execute the formula, verify source bytes,
claim causal identification, modify economics or authorize an Event.

Output always remains `PREPARATION_ONLY_NOT_V29_APPROVAL`,
`formallyVerified=false`, `eventAuthorized=false` and
`parameterApplicationAuthorized=false`.
