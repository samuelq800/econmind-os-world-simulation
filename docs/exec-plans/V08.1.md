## Planned change

Add World-owned inventory accounts, exact positions and immutable balanced
postings across AVAILABLE, RESERVED and IN_TRANSIT. Provide reservation,
release and dispatch primitives only. Quantity arithmetic is exact-or-reject;
out-of-domain results fail explicitly. Do not implement Resource/Trade engines.

## Validation and exit

Property and concurrent database tests prove quantity conservation, unit
isolation, non-negative stock, exact-full reservation, duplicate safety and no
double allocation using the shared exact oracle and canonical equality.
