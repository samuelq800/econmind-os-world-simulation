## Bound authority

V20.1 is an isolated pure-Core candidate for the E17 contract, not a
NORMAL-mode package start. The authoritative plan requires V08.3, V18.3 and
V19.3. This candidate preserves those dependencies and does not alter global
status, Gate state, product flow, persistent state, or deployment authority.

## Exact scope

- Bind exactly one caller-owned LC↔GCU rate to each country per supplied
  valuation snapshot. It creates no 70×69 bilateral rate matrix.
- Require a supplied rate fact, supplied rounding-decision fact, and supplied
  integer simulation-millisecond valuation time for every conversion. Missing
  or mismatched facts fail closed; Core selects no default rate or rounding.
- Use canonical exact decimal/money values and produce canonical replay proof,
  source/predecessor/snapshot/hash/time bindings, and a non-authoritative
  before/delta/after valuation trace.

## Exclusions

No exchange-rate policy, spread, currency registry, macro formula, Command,
Event, receipt, ledger/posting, rate persistence, database/RLS/migration,
API/worker/UI, authorization, production action, or status/Gate mutation.
