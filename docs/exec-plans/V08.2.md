# Execution plan for V08.2

## Authority and entry gate

- R2 title: 金融 Accounts/Postings 基础.
- Hard dependency: V08.1.
- JIT gate: no ADR-08 approval is needed to inherit exact-or-reject and forbid
  rounding; any true rounding/FX/minor-unit requirement stops this sprint.
- Current status: `PLANNED`.

## Planned change

Add financial accounts, exact GCU positions and immutable balanced posting
batches using Money/WorldDecimal. Accepted operations return an exact canonical
result or deterministically reject out-of-domain. No Banking, FX, credit,
reserve or monetary-creation behavior is included.

## Validation and exit

Test sum-before=sum-after, insufficient balance, missing/unequal/duplicate leg,
asset mismatch, overflow and JS-number leakage against the shared exact oracle.
Every unbalanced batch must roll back; tolerance-based equality is forbidden.
