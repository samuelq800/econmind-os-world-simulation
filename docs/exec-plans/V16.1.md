# V16.1 — E06 Housing Foundation-Mode Candidate

## Status and boundary

`FOUNDATION_IMPLEMENTED_UNVERIFIED`. This is a pure Core candidate, not V16.1
implementation or a housing programme action.

## Scope

- Read explicitly identified housing stock, household demand, occupancy, rent,
  subsidy and Project commission records.
- Return exact housing-unit stock, vacancy, household gap and retained rent /
  subsidy inputs with a replay trace.
- A positive housing-unit delta requires a `COMMISSIONED` project handoff with
  project, commission and simulation-time IDs. Subsidy has no supply effect.

## Owners and exclusions

Project remains the future source of commissions; Social/Fiscal owns benefit
policy/payment; Banking/CB owns mortgage conditions. Rent movement has no
default formula and is preserved as a caller-owned versioned state input.

## Evidence target

Focused vectors prove that subsidy cannot change units and only a commission
can add habitable units. No project command, funding, payment, database or UI
work is included.
