# Execution plan for V07.1

## Authority and entry gate

- R2 title: Command/Event Schema 与不可变 Ledger.
- Hard dependencies: V02.3, V03.3, V05.3, V06.3.
- JIT gate: ADR-11/17 and ADR-20 timing approved. ADR-16 is required only before
  candidate DDL is merged/promoted; branch-local artifacts remain provisional.
- Current status: `PLANNED`.

## Planned change

Add canonical command/event envelopes, schema/type registries, repaired
V03-based fingerprinting, World head and ordered append-only event persistence.
The envelope keeps external UUID `AuthSubject` distinct from resolved World
actor/country/Office IDs. Fingerprint/Event bytes admit inert canonical data and
trusted explicit adapters only. API may write immutable submission only; worker
assigns authoritative event ordering.

## Validation and exit

Test schema/version/decimal attacks, same-ID different-payload rejection,
behavioral serializer/getter/Proxy rejection, contiguous sequence and database
denial of historical UPDATE/DELETE. Verify commit/path/byte-hash provenance and
rehearse the ordered migration on clean and existing isolated databases.
