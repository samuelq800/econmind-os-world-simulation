# Execution plan for V09.3

## Authority and entry gate

- R2 title: 故障注入与恢复矩阵.
- Hard dependency: V09.2.
- Current status: `PLANNED`.

## Planned change

Add abandoned-claim recovery, durable duplicate recognition, ledger/head
reconciliation, outbox retry and projection rebuild hook. Recovery never relies
on process memory.

## Validation and exit

Run exception, connection-loss, API/worker kill, lease expiry, stale version,
notification interruption, corrupt watermark and restart scenarios against an
isolated real database. Also prove unsafe runtime configuration fails before
authoritative persistence/recovery starts. Unit-only simulation is insufficient.
