# V14.3 — Facility Handoff and Project Invariant Foundation-Mode Candidate

## Status and boundary

`FOUNDATION_IMPLEMENTED_UNVERIFIED`. This candidate emits only an inert,
deterministic facility-handoff proposal; it does not create a facility owner or
authoritative capacity state.

## Scope and acceptance target

A handoff proposal exists only when explicit project progress equals its total,
the caller-bound right/approval/funding/reservation/workforce inputs permit
construction, commissioning passes, and non-empty mandatory consumed-input
evidence references are present. It names exactly one facility owner and one
capacity before/delta/after trace.

This prevents approved or paid-but-unbuilt projects from becoming capacity and
does not calculate GDP, pricing, default, or policy effects.

## Dependency retained

V14.3 retains V14.2 as its normal-mode hard dependency. The future
authoritative project/facility owner remains responsible for applying any
handoff.
