# V20.2 — External Finance/Capital/Intervention foundation plan

**Candidate state:** `FOUNDATION_IMPLEMENTED_UNVERIFIED`
**Hard dependency:** V20.1 (plus preserved package prerequisites V08.3, V18.3,
V19.3)

## Exact scope

- Model caller-provided private FX settlement through distinct private payer,
  dealer and payee balances. The interface excludes official-reserve fields,
  making private import unable to debit official reserves.
- Model bilateral GCU external-debt facts whose creditor asset and debtor
  liability must reconcile before and after each exact draw or repayment.
- Model official intervention and sterilization only as explicit caller facts
  with supplied deltas. Core selects no intervention amount, spread,
  capital-control, or sterilization formula.
- Bind scoped caller uniqueness witnesses to settlement/operation references;
  a later authoritative writer owns durable idempotency and persistence.

## Exclusions

No account/ledger creation, posting, Command/Event/receipt, durable balance,
foreign-reserve policy, database, migration, API, worker, UI, authorization,
production, status or Gate change.
