## Narrow implementation

Add one pure `packages/core/src/orchestration` validator for a single World configuration containing only the World ID, current shared Core model version, configured positive country count, existing Simulation Clock version, and simulation-time economic expiry discipline. Exact keys and canonical values are mandatory; no mode/discriminator, policy branch, hard-coded 70, buff, admission/registration rule, cutoff policy, economic engine or state mutation is introduced. The result is an immutable, versioned canonical snapshot and deterministic SHA-256 binding.

The only bridge takes an existing Core replay input for the same World/model and passes it unchanged to the already existing `replayAuthoritativeEvents` path. The test replays identical opening/Events twice through that shared path to demonstrate deterministic equivalence for the tested input, not a cross-mode claim or product exit gate.
