# V15.1 — E04 Education Foundation-Mode Candidate

## Status and boundary

`FOUNDATION_IMPLEMENTED_UNVERIFIED`. This is a pure `packages/core` calculation
candidate, not the start of V15.1. It creates no command, event, worker path,
database state, migration, RLS policy, API route, UI behaviour, or production
effect. V14.3 remains an unmet controlling dependency.

## Scope

- Read inert, evidence-bound education cohort, teacher, seat, capacity,
  applicant, duration, outcome and skill-stock facts.
- Return exact, unit-labelled enrolment/graduation values plus an explicit
  vocational/higher skill-handoff record and replay trace.
- Validate caller-owned available capacity and admissions/graduation outcome
  facts against applicants, teachers, seats, budget capacity and duration.

## Owners and exclusions

Education remains the future owner of cohorts/capacity; Labour remains the
future owner of the received skill stock. The kernel writes neither. Finance,
Project, Population and Labour values are inputs only. No completion, dropout,
teacher ratio, skill transition, time, or productivity formula/default is added.

## Evidence target

Focused vectors prove that zero teachers or seats prevent enrolment/graduation,
duration prevents early graduation, and a successful handoff has exact
person-unit before/after traceability. Required final checks are focused tests,
Core typecheck/build, architecture boundary and secret checks.
