## Narrow candidate

Add an isolated strict parser under `packages/core/src/opening` for caller-supplied Season country configuration and per-country population, resource, facility, technology, account and trade-dependency opening facts. Country count comes from configuration (within the Master design cap), never a hardcoded set of 70 IDs. Every configured country must have at least one explicitly classified item in each domain; `MISSING` is not zero. Values retain exact canonical decimal text and measurable units; counts are integral, shares are dimensionless `[0,1]`, currency amounts have explicit currency. Each admitted value binds an immutable source reference and source kind (`OBSERVED_SNAPSHOT`, `DESIGN_ASSUMPTION`, or `LEGACY_INDEX` only for quarantined index records), locator/version/digest, and an origin-specific assumption or derivation reference. Legacy 0–100 indexes cannot become a unit-bearing value. Mixed/mismatched sources, undocumented assumptions, duplicate fields, unknown countries/counterparties, missing units and noncanonical numerics fail closed. Return a deterministic canonical hash preimage, not an authoritative seed or an externally verified dataset claim.

The V08 `OpeningSource`/`OpeningSeed` code remains the authoritative ledger-opening integration point. This candidate does not create financial postings, inventory, geological state, exchange rates, NPC policy or live World State. Later V27 work must bind actual data snapshots and reconcile complete 70-country economics before any seed can be authoritative.
