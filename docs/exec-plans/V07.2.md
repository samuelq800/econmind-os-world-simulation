# Execution plan for V07.2

## Authority and entry gate

- R2 title: Receipts/Outbox/Idempotency.
- Hard dependency: V07.1.
- Current status: `PLANNED`.

## Planned change

Add durable acceptance acknowledgement, final receipt, idempotency record,
worker claim and retry-safe outbox. Exact duplicate returns stored results; same
key/ID with changed fingerprint conflicts. Consumer delivery state is separate
from immutable economic events. An intake authorization context is not
authority: before protected execution the server re-resolves current identity,
membership, country, Office, capability and authorization revision.

## Validation and exit

Test sequential/concurrent duplicate, changed intent, dropped response, restart,
outbox redelivery and rejected zero-mutation outcomes. No retry may duplicate an
economic effect; notifications remain safely redeliverable.
