## 正式构造器阻断点：不要把 TEST_ONLY guard 改宽

1. **真实输入与 seed**：`OfficialOpeningBundleLoader` + `preflightOfficialOpeningBundle` 已存在，只读验证不等于 admission。`official-opening-bundle-preflight.ts:42` 明确保留 `REAL_FINANCIAL_PRODUCER_NOT_CONNECTED` / `FORMAL_LC_FX_AND_COMPLETE_CB_REGISTER_PRODUCER`。需 E/C 对真实来源及 owner 决策逐项绑定，不合成阳性数据。
2. **Admission 发布**：`OfficialOpeningAdmissionPublicationService` 已实现私有 authority/source/role/seed/head 校验与事务后 ADMITTED readback；不能再描述为“完全没有 publisher 实现”。但它不安装进 startup/HTTP/Clock，也不 bootstrap seed。`database/proposals/runtime-read-binding-storage.sql:81` 仍有 `ADMISSION_PUBLICATION_ENTRYPOINT_MISSING` veto；正式数据库的发布入口、迁移发布链、最小权限和私有批准需单独受控交付。本轮没有检查或改变任何已部署数据库。
3. **当前授权与席位**：需要实际 JWT verifier pins、AuthSubject→actor/current membership/country/Office/capability/revision、持久化 seat/read binding、受控 entitlement publisher。多 Office 的 subject 不能随意选第一条 COUNTRY binding；O 测试已保留 ambiguous `NOT_CONNECTED`，后续需明确契约。
4. **唯一正式消费者**：`createIsolatedFinancialRuntimeComposition` 限 `WORLD_C_ISOLATED_*`、owned loopback DB、postgres 测试执行角色；`createDurableCommandConsumptionPreparation:135` 限 local/CI。不能改 env 或解除这些限制来“启动正式世界”。应在已批准边界下复用其既有 ledger/repository/candidate ports，构造 owner-owned 正式 host，显式注入唯一 lease/fence、Clock、可信领域 reader、automatic producer、lifecycle/recovery。
5. **调度与重启**：正式 scheduler 必须由同一已持久化 Clock/顺序 lineage 恢复，不能用 HTTP body SimTime。`simulation-scheduler.ts:178` / `:205` 的 completed-prefix invariant 覆盖状态构造；后续恢复不得绕开该构造器。普通完整提交后 restart 与中断后 abandoned-claim recovery 是不同验收项。
6. **API 与外部宿主**：`createNonactivatedRuntimeApiHost` 已组装 projection/FINAL/financial-intake/office-command 四条明确路由，缺 config 时 disconnected，仍不安装 listener/TLS/启动 worker。需要 G 的 server-owned pools、admitted pins、actor resolver、私有 runtime 和 owner-frozen Clock。`production-runtime-binding.ts` 只是 consistency checker，不颁发 authority。当前 `apps/world-api/cloudflare/runtime-api.mjs` 仍为 HOLD server，不能从某次 HOLD 部署外推本 baseline 已正式激活。
7. **投影与隐私**：现有 publisher/strict consumer 可复用，但正式 committed watermark outbox consumer、重建与授权结果来源仍需连接。Finance raw carrier 缺失、Industry result source 缺失必须继续显示不可用，不能从 event count/hash 推算经济结果。
