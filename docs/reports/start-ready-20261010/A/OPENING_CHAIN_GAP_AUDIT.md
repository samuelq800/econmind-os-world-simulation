## Minimum engineering sequence and risk/dependencies

1. **Contract first:** agree formal LC/FX, complete-register/valuation and versioned selection/adoption bindings. Inputs/authority remain required even after code exists. Preserve frozen originals and historical diagnostic reports; update version selection through reviewed adapters, not by weakening pins.
2. **Formal carrier + producer:** introduce a separately trusted server loader and deterministic producer using approved subset rules and existing Core multi-batch interfaces. Do not lift TEST_ONLY guards or extend legacy blanket approval. P0 financial/conservation/source-authority change; depends on exact values, completeness and adoption.
3. **One derivation shared by preflight and publisher:** route both through the same validated formal seed derivation, retaining independent source-byte and authorization rechecks. Version the assembly contract as necessary; preserve backward diagnostic handling without accepting GCU-only formal seeds. P0 provenance/denomination change; independent review required.
4. **Explicit resumable handoff:** expose a private preparation composition/handoff for load → validate → authorized bootstrap → durable readback → sole publish → committed admission readback. Do not add a second publisher or start automatically. Cross-transaction failures/unknown acknowledgements must be distinguishable; retry cannot change World/seed/fingerprint. Coordinate interfaces only with G execution-host and E DB/SQL owners; this audit neither designs their internals nor establishes their readiness. No migration is proposed here; necessity must be assessed by schema owner against existing stores.

Focused future tests: real non-fixture LC package with FX != 1; full 70-country coverage; declared-but-incomplete holding versus approved absence versus zero; missing valuation/completeness; exact conversion/range rejection; complete CB negative net worth without backing plug; reciprocal claims and per-currency conservation; subset scope preservation; changed bytes/versions/World/seed; canonical ordering/restart fingerprint; preflight/publisher identical seed; bootstrap success then publication failure and exact retry; conflicting retry; durable readback mismatch; authorization expiry/revocation before commit.
