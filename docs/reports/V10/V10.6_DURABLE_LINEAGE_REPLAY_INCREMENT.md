read of the immutable opening seed, World head, authoritative Command/Event
facts, Inventory Postings, and Financial Posting batches. It reconstructs the
same V08 ledger state solely through Core constructors and

order, Posting causation, or final head version/sequence do not recompute. It
accepts no browser data, cache, current balance, fixture provenance, or
caller-provided state. `WorldOpeningSeedStore.loadFrom` lets this operation
retain one server transaction snapshot without bypassing canonical seed checks.
