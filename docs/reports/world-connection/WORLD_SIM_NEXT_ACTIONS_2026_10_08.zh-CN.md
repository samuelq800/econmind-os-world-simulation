## 1. 现在要交付什么

把现有国家页面、地图、开局来源和经济规则，接成一个多人共享的经济世界：
玩家登录并进入合法国家/职位后提交操作，由后台统一执行，保存结果，再向有权用户展示。
所有人读取同一权威 World State；页面、缓存和预测均由它派生。

目标链路：

```text
经审计的开局来源 → 唯一正式 World 的开局状态
玩家页面 → API 身份/职位检查 → 唯一命令队列
→ Worker/Core 结算与持久化 → 授权查询 → 页面显示真实结果
```

当前源码已具备其中许多机制，但不能据此报告“正式世界已经运行”。
仓库记录为正式经济引擎 `NOT_ACTIVATED`，Gate B `PENDING`。

## 4. 服务器和 Worker：分别是什么

| 部件                | 作用                                        | 要准备什么                                                                         |
| ------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------- |
| world-web           | 展示国家和职位，提交操作，读取授权结果      | 正式静态发布与 API 地址/来源绑定                                                   |
| world-api           | 校验登录、国家/职位权限，接受命令并提供查询 | 正式 HTTPS 入口、JWT issuer/audience/JWKS、允许的前端 Origin、受限数据库身份       |
| world-worker        | 唯一权威执行，调用 Core 结算与推进模拟时间  | 可持续运行 Node 程序的目标、进程监督、唯一 writer lease/fence、暂停/恢复和回滚方案 |
| PostgreSQL/Supabase | 保存权威状态、命令、事件和结算结果          | 指定项目/环境/namespace/role，走唯一批准的 schema 发布路径                         |

服务器是承载 API/Worker 的运行环境，Worker 是执行程序；二者通常不是二选一。
本仓库的 `world-worker` 是 Node/TypeScript 后台程序，不等于浏览器 Web Worker，
也不能凭名字认定它可以直接部署到某个云平台的同名服务。

当前 `apps/world-worker/src/main.ts` 进入 `runtime.ts`，默认仍是健康检查服务，
返回 `simulationEnabled:false`。仅运行这个入口或看到 `/readyz` 成功，不能证明经济循环启动。
`production-runtime-binding.ts` 也明确只检查引用一致性，
`evidenceVerification=NOT_PERFORMED`、`runtimeReady=false`，不是部署验收器。

### 运行环境需明确的最小信息

1. 现有可用的 API/Worker 运行目标，以及其管理/发布责任人；若无，再确认采购范围和预算。
2. API 正式域名、TLS 与前端 Origin；Worker 内部运行目标和构建版本。
3. 数据库项目、环境、`world_v2` namespace、各服务所需的受限角色与迁移发布责任人。
4. 身份项目及合法用户/席位发布路径，与同一 World/Seed 绑定。
5. Worker 生命周期、日志、健康与业务监测、备份/恢复和回滚责任。

本文不推荐机器规格或供应商：尚无实际运行负载和目标环境证据，无法据此报价。
密钥通过既定秘密配置路径注入，清单只记录配置项和责任人，不收集明文密钥。

## 7. 怎样才算真的能玩

- 真实用户只能操作合法国家和职位，撤权后立即按规定拒绝。
- 操作有权威回执和真实状态变化；页面区分 QUEUED/FINALIZED 队列确认与经济执行结果。
- 金钱、库存、产权和跨域变化按 Core 精确规则结算；重复提交不重复产生效果。
- UI 读取同一 admission/Seed/head 的授权结果；未知或无权限不显示成零余额。
- Worker 单一写入，停止/恢复、重试和重建不重复结算；时钟行为符合已批准规则。
- 实际执行的命令、环境、版本、退出码与读回留有证据；未覆盖的职位/模式如实保留未完成。

正式最小闭环通过，只证明对应范围；不自动完成六 Office、70 国全部玩法或整个 Gate B。
