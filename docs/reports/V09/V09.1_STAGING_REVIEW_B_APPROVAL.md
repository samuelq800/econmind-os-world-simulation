## Closure evidence

The original finding was that a PostgreSQL URI with approved WHATWG authority
could use query parameters to make `pg@8.16.3` select a different host, port or
user, or turn TLS off. The reviewed target closes that path before any
connection attempt:

- It accepts exactly the literal `?ssl=true` query and no fragment, extra,
  duplicate or encoded query form.
- It constructs `pg.Client` only to inspect `connectionParameters`, without
  calling `connect()`, and requires the effective host, port, user, database
  and TLS state to equal the owner-approved contract.
- It rejects the connection-related `PG*` environment overrides before that
  inspection.
