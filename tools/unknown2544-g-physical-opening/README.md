# Fixed physical construction references

`selectPhysicalReference({ bundleRevision: BUNDLE_REVISION, countryId: 'COUNTRY_02' })`
reads fixed repository files and exactly one ten-country chunk. The only economic
request fields are `bundleRevision` and canonical `COUNTRY_01` through
`COUNTRY_70`. Unknown keys, amounts, policy, periods, paths, pins and authority
overrides are rejected. No network or external-directory fallback exists.

The module pins `data/physical-opening-candidates/2026-10-23-g-v2/manifest.json`
to SHA256 `3f88cbfd8787c858aec47b741fac32fccdcabcf724e7ba3c4dcc97a40367c0fd`.
That immutable design index retains its historical preparation status; it is
provenance, not a mutable release-status record. All selected source bytes are
verified before parsing. `readPhysicalReferenceSources` exposes the same fixed
buffers for offline verification; `assemblePhysicalReference` accepts only those
independently pinned buffers and the same closed request. It cannot accept new
pins. Buffers are detached before parsing. Results are deeply frozen.

The existing lossless parser and exact decimal oracle preserve source decimal
lexemes. Construction reproduces the selected ten records and checks full
structural equality with the fixed chunk. A bounded BigInt serializer reduces
fractions; nonterminating resident-demand/yield quotients retain numerator and
denominator with `valueExactDecimal: null`. Numeric identity indices and original
climate display metadata do not enter quantity calculations. No quantity uses
binary floating point or rounded division.

These are `CONSTRUCTED_NOT_ADOPTED`, partial references. The 50/15 resident-only
parameters are an unadopted 70-country applicability proposal. The R3 receipt
adopts only eight COUNTRY_01 coefficients; the other 69 copies remain proposals.
Required medical/public additions, actual floors, all nine original actual
values, actual currency, date and World remain null. All acceptance stages,
source admission, runtime connection and production authority remain false;
original fields closed remains zero. No 8-hour worker-day, 24-hour SIM_DAY,
default FX, water rights, accepted delivery or transport approval is inferred.
MW is not converted to MWh; frozen C13 199.8 TONNE is not relabelled TONNE_KM.
Supply sums do not establish independent basin rights or actual availability.

C remains the sole shared physical-bridge author. The structured record,
original IDs, applicability and source trace are an input to C's separately
reviewed contract, not an adopted provider. This package does not include the
external recipe/old C16 packet needed to repeat the old COUNTRY_01 reader. The
prior successful single reader output is provenance only; this suite does not
replay it or the old 770-check verifier.
