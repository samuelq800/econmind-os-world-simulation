# C original-field first-16 isolated bridge

## Explicit COUNTRY13 reference extension

The default sixteen-ID contract and COUNTRY01 adopted route are unchanged.
An optional own constructor key `country13Transport` must contain exactly
`contract: 'C13_PINNED_REFERENCE_FREIGHT_EXTENSION_V1'`, `transportBytes` and
`catalogueBytes`. Missing, undefined, malformed or drifted inputs reject without
falling back. It adds only COUNTRY13 `transportMinimum` to reference reads.
The bridge calls the existing pinned accepted-freight extractor, returning
199.8 reference TONNE from the single retained event. This never fills the
original TONNE_KM/PERIOD minimum: distance, actual period, title, World receipt
and service-floor admission remain unbound. No source adoption or closure.

The active packet has seventeen rows and effective B13 subset count five.
Historical row subset counts describe the legacy16 or extension1 cohort,
as explicitly labelled; the old sixteen rows and their read outputs stay intact.

The sole formal suite is `tests/world-core/c-country13-transport-reference.test.ts`.
It decodes six exact historical byte buffers from a bounded inert gzip fixture
and reuses five tracked files, all with original whole-byte hashes. No absolute
source locator is followed, no network/extraction/mock/skip is permitted.
Known internal provenance paths are retained under the Root exact-source
distribution scope; this is not general privacy/copyright certification or
permission for Web/API/runtime distribution.

Status: IMPLEMENTED_UNVERIFIED. Original closures: **0**. This is a reference-input
consumer, not runtime, source admission, economic adoption, or World construction.

Exact subset: COUNTRY_01 and COUNTRY_53, eight original B10–B13 fields each.
Each parent has four IDs in this package, not a complete parent batch. The existing
full-batch acceptance CLI is not invoked or replaced. Root alone writes the register.

`createOriginalFieldConsumer` verifies nine exact pinned buffers before constructing
an immutable, original-ID-keyed candidate. It reuses merged C lossless parsing/exact
decimal helpers and frozen physical, water and repair outputs. It does **not** invoke
their source extractors, 426-action builder, large journals or 140-day simulations.

The executable read returns concrete candidate inputs, not only status flags:

- B10: allocated posts, exact reference work-days/wages/materials by action and
  COUNTRY_01's proposed water recipe. Posts and worker-days never become hours.
- B11: country/region-bound raw domestic allocations, potable-chain repair inputs,
  and COUNTRY_01's proposed two-yield water recipe. No raw quota is net potable flow.
- B12: MW/MWh-capacity inputs and COUNTRY_53's exact repair-input vector. Repair
  electricity is an input, not generated/delivered MWh or a national minimum.
- B13: country-bound unsigned cargo plans, estimated distances/proposed GCU costs
  and warehouse repair references. No plan becomes an arrival or native freight cost.

Each original measure remains `null`, with exact original acceptance/dependency
strings, source hashes/pointers/leaves and missing-scope blockers. Native currency
candidates are separate from actual field currency. Reference wages are already
inside each known repair subtotal: there is no cross-action sum or recurring full
cost computation, and no extra wage charge.

The pinned adopted D04 receipt supports only its stated opening policies. R3
coefficients, conflicting versions, FX/reference costs and unsigned plans are not
operationally adopted by this tool. Missing B02/service-floor, recipe adoption,
timesheets/hours, rights/quality, actual delivery, period/World scope, and complete
inclusive-or-disjoint native cost evidence remain blockers. They are not new policy
votes, and missing quantities are never defaulted to zero.

Reads require `REFERENCE_INPUTS_ONLY`, exact original ID/country/unit and null actual
period/currency. Actual/minimum/complete-cost promotion, forged adoption or fixture
flags, double-count options, source drift, and cross-country/unit/scope mismatches
are rejected. Returned snapshots are recursively immutable; supplied replacement
packets are not accepted.
